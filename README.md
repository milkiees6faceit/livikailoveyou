# 💌 Сайт-валентинка

Интерактивный романтический сайт из 4 экранов: вопрос с убегающей кнопкой,
проверка секретного слова, анимированное письмо в конверте и финальная
страница с вашим фото и обнимашками.

**Текущая версия (v2):** исправлено обрезание письма и фото сверху,
фон перерисован нарисованными SVG-сердечками (без эмодзи), переходы
стабилизированы, добавлена адаптация под телефоны и prefers-reduced-motion.

## 📁 Структура проекта

```
index.html            — основная страница
style.css             — все стили и анимации
script.js             — вся логика (кнопки, слово, письмо)
images/our-photo.jpg  — ваша совместная фотография (ОБЯЗАТЕЛЬНО загрузите!)
README.md             — этот файл
```

## ⚠️ Важно про фотографию

Фото загружается **с файлом `our-photo.jpg` внутри папки `images`**.
На GitHub: Add file → Upload files → перетащи **папку images целиком**
(или создай папку images и загрузи файл в неё). Если загрузить фото просто
в корень — сайт его не найдёт и покажет заглушку.

## ✏️ Что можно поменять под себя

| Что | Где |
|---|---|
| Текст письма | `script.js` → переменная `LETTER_TEXT` |
| Секретное слово (сейчас `умница`) | `script.js` → переменная `SECRET_WORD` |
| Совместное фото | замени файл `images/our-photo.jpg` (имя оставь тем же) |

## 🔄 Как обновить уже опубликованный сайт

1. Открой свой репозиторий на GitHub.
2. Для каждого изменённого файла (`index.html`, `style.css`, `script.js`):
   кликни на файл → иконка карандаша ✏️ (Edit) → выдели всё (Ctrl+A) →
   удали → вставь новый код → **Commit changes**.
3. Фото: Add file → Upload files → перетащи папку `images`.
4. Подожди 1–2 минуты — сайт обновится сам, ничего включать заново не нужно.

## 🌐 Первая публикация (если сайта ещё нет)

1. github.com → **New repository** → имя (например `livikailoveyou`) → **Public** → **Create repository**.
2. **uploading an existing file** → перетащи все файлы и папку `images` → **Commit changes**.
3. **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → **Save**.
4. Через 1–2 минуты ссылка вида `https://ЛОГИН.github.io/ИМЯ/` готова.

## ✅ Локальная проверка

Открой `index.html` двойным кликом — сайт работает без сервера.
