# 💌 Сайт-валентинка

Интерактивный романтический сайт из 4 экранов: вопрос с убегающей кнопкой,
проверка секретного слова, анимированное письмо в конверте и финальная
страница с вашим фото и обнимашками.

## 📁 Структура проекта

```
index.html          — основная страница
style.css           — все стили и анимации
script.js           — вся логика (кнопки, проверка слова, письмо)
images/our-photo.jpg — ваша совместная фотография
README.md           — этот файл
```

## ✏️ Что можно поменять под себя

| Что | Где |
|---|---|
| Текст письма | `script.js` → переменная `LETTER_TEXT` |
| Секретное слово (сейчас `умница`) | `script.js` → переменная `SECRET_WORD` |
| Совместное фото | замени файл `images/our-photo.jpg` (имя оставь тем же) |

Если фото отсутствует — на сайте показывается милая заглушка, сайт не ломается.

## 🌐 Публикация на GitHub Pages (без командной строки)

1. Зайди на https://github.com и нажми **New repository** (зелёная кнопка).
2. Придумай название репозитория (например `valentine`), оставь его **Public**, нажми **Create repository**.
3. На странице репозитория нажми **uploading an existing file** (или кнопку `Add file` → `Upload files`).
4. Перетащи в окно **все файлы и папку проекта целиком**: `index.html`, `style.css`, `script.js`, `README.md` и папку `images` (с файлом `our-photo.jpg` внутри). Нажми **Commit changes**.
5. Зайди в **Settings** → слева **Pages**.
6. В разделе **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)** → нажми **Save**.
7. Через 1–2 минуты вверху страницы **Settings → Pages** появится ссылка вида:
   `https://ТВОЙ_ЛОГИН.github.io/valentine/` — это и есть адрес сайта.
8. Открой ссылку на телефоне и проверь, что всё работает. Готово — можно отправлять девушке 💗

## ✅ Проверка перед публикацией

Просто открой `index.html` двойным кликом в браузере — сайт работает локально,
без сервера и сборки.
